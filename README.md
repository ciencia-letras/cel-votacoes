# Votações na sala (CeL)

Página onde os formandos respondem às perguntas da sessão, aberta pelo código QR do deck.

**Cada turma tem o seu endereço**, para que turmas em simultâneo não se misturem:

```
https://ciencia-letras.github.io/cel-votacoes/<entidade>/<módulo>/<turma>/
```

A página tira a sala do próprio endereço; qualquer endereço funciona (o `404.html` é a mesma página). Só HTML: não tem dados nem chaves e não guarda nomes.
